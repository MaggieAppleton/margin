# Layout comparison (disposable)

Eight sample notes at a 1280px viewport: `layout-single.html` vs `layout-grid.html`
(screenshots: `screenshot-single-1280.png`, `screenshot-grid-1280.png`).

**Choice: compact single column.**

- Reads in one unambiguous top-to-bottom order; the grid zigzags left-right, so newest/oldest order is unclear.
- Uneven note lengths leave ragged gaps in the grid; the single column stays tidy.
- Both fit all eight notes in one screen at 1280x900, so the grid gains nothing.
- A ~640px column has comfortable line lengths; grid cards are fine but the wide add-note box feels oversized.

This is a prototype only; the product layout is not decided or built here.

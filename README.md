# Margin

Notes that remind you.

This repository is built from a Chopin living document. The document is the
source of truth: change the document, and the code follows.

## Development

Browser-only Vite + React + TypeScript app (no backend).

```
npm install      # install dependencies
npm run dev      # start the dev server
npm run build    # type-check (tsc -b) and build to dist/
npm run preview  # serve the production build
```
